# Domain docs

Use a single-context layout: GLOSSARY.md at the repository root
and ADRs in the existing docs/decisions/ directory.

Before exploring an area:
- Read GLOSSARY.md if it exists.
- Read decisions in docs/decisions/ relevant to that area.
- Follow the research state and task routing in AGENTS.md.

Proceed if the glossary is absent; create it only when domain
modeling resolves terminology.

Use glossary terms consistently in issues, hypotheses, tests and proposals.
Surface conflicts with existing decisions explicitly.
Protocol or evaluation changes follow the review requirements in AGENTS.md.
